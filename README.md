# LAST 200 HOURS

Enterprise-style industrial AI predictive maintenance platform powered by Hermes Agent.

Run:

```powershell
pip install -r requirements.txt
python app.py
```

Open:

```text
http://127.0.0.1:5000
```

Current capabilities:

- CSV telemetry replay
- real telemetry ingestion through `POST /api/telemetry`
- RUL prediction
- anomaly detection
- failure probability scoring
- Hermes Agent reasoning
- maintenance recommendations
- future degradation simulation
- PDF reports
- simulator data generation
- model evaluation/retraining endpoints
- enterprise dashboard
